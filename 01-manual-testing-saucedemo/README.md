# Ручное тестирование: Swag Labs (SauceDemo)

Учебный проект по ручному тестированию веб-приложения https://www.saucedemo.com.
Показывает полный цикл работы QA: планирование, тест-дизайн, выполнение, оформление дефектов, отчётность.

## Что внутри

| [docs/02-test-cases.md](docs/02-test-cases.md) | 51 тест-кейс (авторизация, каталог, корзина, оформление, меню, UI) |

| `screenshots/` | Скриншоты к багам |

## Техники
Эквивалентное разбиение, граничные значения, позитивные/негативные сценарии, исследовательское тестирование.
