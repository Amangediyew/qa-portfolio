## BUG-004: [Меню] После Reset App State кнопки товаров остаются в состоянии Remove

**Статус:** New
**Severity:** Minor
**Priority:** Medium
**Дата обнаружения:** 2026-11-02
**Автор:** Амангельдыев Эзиз
**Связанный тест-кейс:** TC-CART-10

### Окружение
- Приложение: https://www.saucedemo.com
- Браузер / версия: Chrome (156.0.8078.74)
- ОС: Windows 10
- Пользователь: `standard_user` / `secret_sauce`

### Шаги воспроизведения
1. Открыть https://www.saucedemo.com
2. Войти как `standard_user` / `secret_sauce`
3. Добавить в корзину 2–3 товара (у них кнопка меняется на Remove, на корзине виден счётчик)
4. Нажать на иконку меню → **Reset App State**
5. Не обновляя страницу, посмотреть на кнопки товаров и счётчик корзины

### Фактический результат
После Reset App State счётчик корзины исчезает, но у товаров остаётся кнопка Remove [УТОЧНИТЕ, если у вас иначе]. Кнопки возвращаются в Add to cart только после обновления страницы.

### Ожидаемый результат
Сразу после Reset App State корзина пуста, счётчик исчез, у всех товаров кнопка Add to cart (без обновления страницы).
