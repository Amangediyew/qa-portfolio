## BUG-003: [Корзина] У problem_user часть товаров не добавляется в корзину

**Статус:** New
**Severity:** Critical
**Priority:** High
**Дата обнаружения:** 2026-11-02
**Автор:** Амангельдыев Эзиз
**Связанный тест-кейс:** TC-CART-09

### Окружение
- Приложение: https://www.saucedemo.com
- Браузер / версия: Chrome (156.0.8078.74)
- ОС: Windows 10
- Пользователь: `problem_user` / `secret_sauce`

### Шаги воспроизведения
1. Открыть https://www.saucedemo.com
2. Войти как `problem_user` / `secret_sauce`
3. По очереди нажать Add to cart у каждого из 6 товаров
4. После каждого нажатия проверить кнопку товара и счётчик на иконке корзины
5. Открыть корзину и сравнить её содержимое с добавленными товарами

### Фактический результат
1. Не все товары добавляются в корзину
2. Кнопки "add to cart" не все реагирует (К примеру Sauce Labs Backpack,Sauce Labs Bike Light,Sauce Labs Onesie добавились в корзину но обратно вернуть с помощью кнопки "Remove" не получается)

### Ожидаемый результат
Каждый из 6 товаров добавляется: кнопка меняется на Remove, счётчик корзины увеличивается на 1, товар отображается в корзине (как у `standard_user`).
