# Чек-листы: Swag Labs (SauceDemo)

Отметка: `[ ]` не проверено · `[x]` пройдено · `[!]` дефект (ссылка на баг)

## 1. Smoke-чек-лист (быстрая проверка, ~5 минут)
- [ ] Страница входа открывается
- [ ] Вход `standard_user` / `secret_sauce` выполняется
- [ ] Каталог показывает 6 товаров
- [ ] Товар добавляется в корзину, счётчик обновляется
- [ ] Корзина открывается, товар в ней виден
- [ ] Оформление заказа проходит до сообщения «Thank you for your order!»
- [ ] Выход из системы работает

## 2. Авторизация
- [ ] Вход со всеми 6 тестовыми пользователями
- [ ] Пустые поля: сообщение «Username is required»
- [ ] Пустой пароль: сообщение «Password is required»
- [ ] Неверный пароль / логин: сообщение «do not match any user»
- [ ] `locked_out_user`: сообщение о блокировке
- [ ] Регистр логина и пароля учитывается
- [ ] Пробелы в начале и конце логина
- [ ] Закрытие сообщения об ошибке (крестик)
- [ ] Прямой переход на `/inventory.html`, `/cart.html` без входа
- [ ] Кнопка «Назад» после выхода
- [ ] Вставка (Ctrl+V) и автозаполнение браузера в поля

## 3. Каталог
- [ ] У каждого товара есть изображение, название, описание, цена, кнопка
- [ ] Изображение соответствует товару
- [ ] Сортировка: A→Z, Z→A, цена по возрастанию, цена по убыванию
- [ ] Выбранная сортировка сохраняется после добавления товара
- [ ] Переход в карточку по названию и по картинке
- [ ] В карточке совпадают название, цена, описание
- [ ] «Back to products» возвращает в каталог

## 4. Корзина
- [ ] Добавление одного / нескольких / всех товаров
- [ ] Счётчик на иконке корзины корректен
- [ ] Удаление из каталога и из корзины
- [ ] Корзина сохраняется после обновления страницы
- [ ] Корзина сохраняется после перехода между страницами
- [ ] Один и тот же товар нельзя добавить дважды
- [ ] Continue Shopping возвращает в каталог
- [ ] Reset App State очищает корзину

## 5. Оформление заказа
- [ ] Обязательность полей: First Name, Last Name, Postal Code
- [ ] Тексты ошибок для каждого поля
- [ ] Поля: цифры, спецсимволы, пробелы, очень длинная строка, эмодзи
- [ ] Cancel на шаге 1 и 2
- [ ] Item total равен сумме цен товаров
- [ ] Tax = 8% от Item total (округление до цента)
- [ ] Total = Item total + Tax
- [ ] Список товаров на шаге 2 совпадает с корзиной
- [ ] Finish завершает заказ, корзина очищается
- [ ] Переход назад после завершения заказа
- [ ] Оформление с пустой корзиной

## 6. Меню и навигация
- [ ] Открытие и закрытие бокового меню
- [ ] All Items, About, Logout, Reset App State
- [ ] Логотип и иконка корзины доступны на всех страницах
- [ ] Ссылки в футере (Twitter, Facebook, LinkedIn) открываются

## 7. UI / UX
- [ ] Chrome, Firefox, Edge
- [ ] Разрешения 1920×1080, 1366×768, 375×667
- [ ] Масштаб страницы 50% и 200%
- [ ] Навигация с клавиатуры (Tab, Enter)
- [ ] Опечатки в текстах
- [ ] Консоль браузера (DevTools): нет ошибок JavaScript

## 8. Исследовательский чек-лист (exploratory)
- [ ] Быстрые повторные клики по кнопкам
- [ ] Двойной клик по Add to cart / Checkout
- [ ] Открытие приложения в двух вкладках
- [ ] Изменение URL вручную (`/cart.html`, `/checkout-step-two.html`)
- [ ] Переход на шаг 2 оформления без заполнения шага 1
