# Проект 4. Тестирование мобильного приложения

**Статус:** ⚪ Запланировано

## Цель
Проверить мобильное приложение на реальном устройстве и/или эмуляторе.

## Объект
Любое приложение (open-source или публичное), платформа Android/iOS.

## План
- [ ] Краткий тест-план (устройства, версии ОС, область)
- [ ] 20–30 тест-кейсов и чек-лист
- [ ] Мобильная специфика: поворот экрана, сворачивание/возврат, прерывание звонком, нет сети, смена языка, уведомления, разрешения
- [ ] Логи (`adb logcat`) для найденных багов
- [ ] Баг-репорты со скриншотами и видео

## Структура
- `test-cases/` — тест-кейсы и чек-листы
- `bugs/` — баг-репорты
- `screenshots/` — материалы к багам
