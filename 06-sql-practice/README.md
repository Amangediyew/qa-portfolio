# Проект 6. SQL-практика для тестировщика

**Статус:** ⚪ Запланировано

## Цель
Показать умение проверять данные и находить дефекты на уровне БД.

## База данных
Учебная БД: Sakila, Northwind или Chinook. Подключение через DBeaver.

## План
- [ ] ER-схема и описание таблиц
- [ ] 30–40 запросов: SELECT, WHERE, JOIN, GROUP BY, HAVING, подзапросы
- [ ] Проверки целостности: дубли, записи без родителя (orphan), NULL в обязательных полях
- [ ] Для каждого запроса — комментарий: что проверяем и какой баг можно найти

## Структура
- `queries/` — файлы `.sql` по темам (`01_select.sql`, `02_joins.sql`, `03_data_quality.sql`)
- `screenshots/` — результаты запросов
