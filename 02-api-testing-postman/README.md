# Проект 2. API-тестирование (Postman + Newman)

**Статус:** 🟡 В работе (коллекция готова, нужен прогон и отчёт)

## Цель
Проверить публичное REST API: статус-коды, структура и содержимое ответов, схемы, негативные сценарии и граничные значения.

## Объект тестирования
[JSONPlaceholder](https://jsonplaceholder.typicode.com) — бесплатное тестовое REST API (посты, комментарии, пользователи, задачи, альбомы).
Особенность: запросы записи (POST/PUT/PATCH/DELETE) имитируются, данные на сервере не сохраняются.

## Что внутри
| Папка / файл | Содержание |
|---|---|
| `collection/JSONPlaceholder.postman_collection.json` | Коллекция: 24 запроса с автоматическими проверками |
| `environment/JSONPlaceholder.postman_environment.json` | Окружение: `baseUrl`, `postId`, `userId` |
| `reports/` | HTML-отчёты Newman и скриншоты прогона |

## Состав коллекции
| Папка | Запросы | Что проверяем |
|---|---|---|
| 01 Posts (CRUD) | API-001…008 | GET список / по id / фильтры, POST, PUT, PATCH, DELETE |
| 02 Связанные ресурсы | API-009…015 | Комментарии, пользователи, вложенные ресурсы, фильтры |
| 03 Негативные сценарии | API-016…024 | 404, некорректный id, граничное значение, пустое тело, нет валидации |

## Что проверяется в тестах
- статус-код;
- заголовок `Content-Type`;
- структура ответа (JSON Schema) и типы полей;
- количество элементов и корректность фильтров;
- формат email, уникальность id;
- время ответа менее 2000 мс (проверка на уровне всей коллекции);
- передача данных между запросами через переменные (`createdPostId`).

Запросы с пометкой `[наблюдение]` не «падают» при спорном поведении API, а фиксируют его (например, 200 на удаление несуществующего ресурса).

## Как запустить

### В Postman
1. Import → выбрать оба файла (коллекцию и окружение).
2. Справа сверху выбрать окружение «JSONPlaceholder (prod)».
3. Collection → Run → Run JSONPlaceholder API Tests.

### Через Newman
```
npm install -g newman newman-reporter-htmlextra
newman run collection/JSONPlaceholder.postman_collection.json -e environment/JSONPlaceholder.postman_environment.json -r cli,htmlextra --reporter-htmlextra-export reports/report.html
```
