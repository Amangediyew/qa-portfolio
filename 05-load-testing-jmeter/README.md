# Проект 5. Нагрузочное тестирование (Apache JMeter)

**Статус:** ⚪ Запланировано

## Цель
Определить поведение системы под нарастающей нагрузкой и найти точку деградации.

## Объект
Тестовый сайт, разрешённый для нагрузки (например, BlazeDemo). Нагружать чужие боевые сервисы нельзя.

## План
- [ ] Модель нагрузки: 10 → 50 → 100 виртуальных пользователей
- [ ] Сценарий: поиск, выбор, оформление
- [ ] Thread Group, HTTP Request, Assertions, Timers, Listeners
- [ ] Метрики: среднее и 90/95-й перцентиль времени ответа, пропускная способность, % ошибок
- [ ] HTML-отчёт JMeter и выводы

## Структура
- `scenarios/` — файлы `.jmx`
- `reports/` — HTML-отчёты и графики

## Запуск (без GUI)
```
jmeter -n -t scenarios/<файл>.jmx -l reports/result.jtl -e -o reports/html
```
